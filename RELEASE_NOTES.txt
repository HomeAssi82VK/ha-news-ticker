News Ticker v1.0.6

First regular release of News Ticker for Home Assistant.

Features:
- Up to eight RSS/Atom sources with server-side fetching and caching
- Visual card editor, themes and three animation styles
- Seamless scrolling, including a single headline, and Grid/Sections layout support
- Improved handling of malformed XML responses
- Standard Home Assistant custom-card registration, without experimental internal picker patches

Installation: Find News Ticker in HACS under Integrations, install it and restart Home Assistant Core. Add the News Ticker integration under Devices & services, then register /news_ticker/news-ticker-card.js?v=1.0.6 as a JavaScript module in Dashboard Resources. If the project is not yet listed in your HACS search, use https://github.com/HomeAssi82VK/ha-news-ticker as a custom Integration repository.

This is a normal release, not a GitHub pre-release. The functionality is unchanged from the tested earlier build; feedback from other Home Assistant environments is welcome.
