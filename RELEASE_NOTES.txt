News Ticker Card v1.1.0

New in this stable release:
- Adjustable title field shapes: Pointed, Rounded, Straight.
- Adjustable title field width: 55-360 px or automatic.
- Cinematic Nightglow removed (old configurations fall back to Minimal Dark).
- Feed processing, animations, filtering, clock and editor functionality retained.
- v1.0.7 HTTP download/size-limit review fix and regression tests retained.

After installing via HACS, set the dashboard resource to
/news_ticker/news-ticker-card.js?v=1.1.0
and reload the browser. Restart Home Assistant Core if required after the integration update.
