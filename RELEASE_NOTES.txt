News Ticker v1.0.7

Stability and security maintenance release for HACS review.

Fixes:
- Read RSS/Atom HTTP responses completely in bounded chunks instead of relying on a single StreamReader.read() call.
- Reject a feed as soon as the accumulated body exceeds 1,500,000 bytes, including after HTTP decompression.
- Prevent partial downloads from entering the RSS parser.
- Add isolated regression tests for the HTTP download size limit and multi-chunk responses.

Unchanged: Home Assistant integration setup, public-URL and redirect checks, RSS/Atom parser, editor, themes, animations, and displayed feed content.

Update: Install v1.0.7 through HACS and restart Home Assistant Core. If the JavaScript resource URL includes a cache-busting parameter, change it to /news_ticker/news-ticker-card.js?v=1.0.7 and refresh the browser.

GitHub Release: publish v1.0.7 as a regular release (not a pre-release). This release addresses the size-limit review finding in hacs/default PR #12602.
